# Quản lý tiếp nhận và phân loại yêu cầu bảo hành

Thông tin sinh viên:
- Bùi Thế Anh
- Track SE
- Chuyên đề Tốt nghiệp 1
- HK1 2026–2027

Luồng nghiệp vụ: L2 – Tiếp nhận và phân loại yêu cầu bảo hành

## 1. Mục tiêu

Quản lý tiếp nhận và phân loại yêu cầu bảo hành: nhân viên tiếp nhận tra cứu khách hàng theo số điện thoại, ghi nhận thiết bị và mô tả lỗi, phân loại nhóm sự cố và mức ưu tiên; hệ thống kiểm tra tình trạng bảo hành, sinh hạn cam kết và tạo phiếu ở trạng thái Mới để chuyển sang bước xử lý.

## 2. Yêu cầu môi trường

Stack dự kiến:

- Node.js
- npm
- Next.js
- Express
- PostgreSQL

Biến môi trường: xem .env.example

## 3. Hướng dẫn chạy

> Sẽ được cập nhật khi frontend, backend và database
> được khởi tạo. BT2 yêu cầu quy trình chạy hoàn chỉnh
> không vượt quá 4 bước.

## 4. Cấu trúc thư mục

- `docs/`: tài liệu, sơ đồ và minh chứng.
- `src/`: mã nguồn frontend/backend.
- `src/frontend/`: nơi khởi tạo frontend Next.js.
- `src/backend/`: nơi khởi tạo backend Express.
- `tests/`: unit test và integration test.
- `data/`: dữ liệu mẫu nhỏ dùng cho phát triển/kiểm thử.

## 5. Kiểm thử

Sẽ được cập nhật khi test framework được thiết lập.
